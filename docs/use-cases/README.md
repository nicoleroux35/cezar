# Cas d'Usage Cezar

Collection d'exemples pratiques pour tirer le meilleur parti de Cezar.

## 📚 Guides disponibles

### [Code Review Automatique](code-review.md)
Obtenez des code reviews de qualité instantanées avant de soumettre vos PRs.

**Idéal pour** :
- Reviews avant PR
- Reviews automatiques sur nouveaux PRs
- Détection précoce de bugs
- Apprentissage des bonnes pratiques

**Temps économisé** : 30-60 minutes par PR

---

### [Maintenance Automatisée](maintenance-automation.md)
Automatisez les tâches de maintenance récurrentes.

**Idéal pour** :
- Mises à jour de dépendances
- Nettoyage de code
- Audits de sécurité
- Vérifications régulières

**Temps économisé** : 2-4 heures par semaine

## 🚀 Comment utiliser ces guides

1. **Lisez le cas d'usage** qui correspond à votre besoin
2. **Copiez les workflows** fournis dans `.ai/cezar/workflows/`
3. **Adaptez** à vos besoins spécifiques
4. **Testez** manuellement d'abord
5. **Automatisez** une fois satisfait
